# MySQL-  
このリポジトリは、joinを使い複数の医療データテーブルを結合し、疾患別の平均入院期間、医療費を抽出するクエリについて書いたものとなります。  

## 概要
-使用するDBMS:MySQL  
-主な目的:joinの修得  
-実行環境:DBeaver  

| ファイル名 | 説明 | 主に使っているSQL機能 |
| :--- | :--- | :--- |
| join1 | 疾患別の平均入院期間と医療費 | round,datediff,avg,join |  

## 工夫した点  
-fromの行において、asを省略したテーブル名の別名の付与、onを活用したjoinの結合条件の指定を修得しました。
